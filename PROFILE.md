# Profile graphics

The profile follows the quiet, monochrome design of [Himanshu-MlSHRA's README](https://github.com/Himanshu-MlSHRA/Himanshu-MlSHRA): transparent SVGs, JetBrains Mono, lavender accents, and Simple Icons technology marks. It is personalized for Jee Daguman / Aicyraa.

Edit `README.md` for the biography, featured projects, and contact links. Static title, section headings, and technology grid are generated by `scripts/profile_design.py`. The original SVG chart generators are in `scripts/generate_stats.py`, `scripts/generate_streak.py`, and `scripts/generate_langs.py`. Animations are resolved to their final state so the graphics are readable immediately.

## Refresh

```sh
python scripts/generate.py Aicyraa
```

Python 3.12 is used in Actions. No third-party Python dependencies are required. After these files are pushed to `main`, the workflow refreshes the graphics daily. You can also start it from **Actions → Refresh profile stats → Run workflow**.

To regenerate the complete design from the saved data without network access:

```sh
python scripts/profile_design.py
```

## Data

The public GitHub contribution calendar supplies annual contributions, active days, weekly totals, and streaks. The calendar includes partial weeks at either end. Longest streak refers to that calendar window; the current streak allows today to be unfinished.

Language percentages are calculated from bytes across public, non-fork repositories. They describe repository contents, not proficiency. The public repository counter includes forks. Failed fetches preserve the previous snapshot.

The workflow uses the automatic `GITHUB_TOKEN`. An optional `GH_PAT` secret can provide annual commit and pull request counts in the saved snapshot; those fields are not displayed. Recent events are never substituted for annual contribution totals.
