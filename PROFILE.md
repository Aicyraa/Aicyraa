# Profile graphics

The README contains a transparent SVG panel with a charcoal border with a terminal profile on the left and live contribution analytics on the right. GitHub strips CSS flexbox from README markup, so both columns are composed into one SVG for a stable side-by-side layout. Muted orange accents highlight the terminal commands and best-week statistic.

A matching transparent terminal About panel follows it, introducing the profile as “A builder” with details about projects, languages, and current interests. A grayscale ASCII rendering of the actual GitHub avatar sits in its left column. The standalone name header, contact icons, and projects section have been removed from the README. Streak values and labels are centered within two equal columns without an underline. The toolkit and streak/language analytics each have their own transparent terminal container. The centered toolkit contains 20 monochrome logos, including Prisma, Neon, Supabase, Vercel, Vitest, Jest, Bruno, and Postman.

## Editing

- `README.md`: visible sections, sizing, and alternative text.
- `scripts/profile_design.py`: terminal contents and current focus, container layout, palette, section headings, and tool grid.
- `assets/avatar-ascii.json`: fixed-width character and color samples from the GitHub profile picture, used to reproduce the portrait without network access.
- `assets/icons/`: added SVG logos from [Simple Icons](https://github.com/simple-icons/simple-icons).
- `assets/stack-reference.svg`: original technology marks, retained from the initial [reference profile](https://github.com/Himanshu-MlSHRA/Himanshu-MlSHRA).
- `scripts/generate_stats.py`, `generate_streak.py`, `generate_langs.py`: contribution and language chart renderers. Their original palette is mapped to the current gray and orange palette during rendering.

Embedded JetBrains Mono fonts are retained from the initial adaptation. All SVGs render immediately without animation or external image services.

## Refresh

```sh
python scripts/generate.py Aicyraa
```

Python 3.12 is used in Actions. Install the avatar conversion dependency first with `python -m pip install -r requirements.txt` (Pillow). Offline rendering still uses only the Python standard library. After these files are pushed to `main`, the workflow refreshes the profile panel, analytics, and ASCII avatar daily. A change to your GitHub profile picture appears after the next successful run; this is not an instant update. Failed avatar downloads or conversions retain the saved portrait. It can also be started from **Actions → Refresh profile stats → Run workflow**.

To regenerate all artwork from the saved snapshot without network access:

```sh
python scripts/profile_design.py
```

## Data

The public GitHub contribution calendar supplies annual contributions, active days, weekly totals, and streaks, including partial weeks at either end. Longest streak refers to the calendar window. The current streak allows today to be unfinished.

Language percentages use bytes across public, non-fork repositories and describe repository contents, not proficiency. The public repository counter includes forks. Failed fetches preserve the last successful snapshot.

The workflow uses the automatic `GITHUB_TOKEN`. An optional `GH_PAT` secret can provide annual commit and pull request counts in the saved data, but those fields are not displayed. Recent events are never substituted for annual contribution totals.

## Animated contribution skyline

The graph at the bottom of the README is `skyline.svg`, generated by `scripts/generate_skyline.py`. It is inspired by [Avi Vashishta's contribution-graph tutorial](https://www.avivashishta.com/blog/animate-github-contribution-graph-portfolio), adapted from canvas into a standalone SVG for GitHub README embedding.

Each dated calendar entry becomes a three-faced building. Columns represent weeks, with Sunday through Saturday drawn back to front. Height uses the square root of the daily contribution count, while gray shades use GitHub's own activity levels. The busiest day is highlighted in muted orange and labeled with its actual date and contribution count.

The SVG uses a 16-second CSS animation loop: a left-to-right build lasting about seven seconds, a completed hold, then a fade and reset. It runs as an embedded image without JavaScript. It starts when the image loads, rather than when it scrolls into view, and has no interactive replay control. Reduced-motion preferences disable animation and show the completed skyline; SVG renderers without animation also display its completed state.

The daily refresh saves `daily_contributions` (date, count, and level) in `scripts/data.json`, then rebuilds and commits the skyline alongside the other graphics. Fetch failures retain the saved calendar. Run `python scripts/profile_design.py` to regenerate all graphics offline from that snapshot.

Focused checks: `python -m unittest discover -s tests -v`.
